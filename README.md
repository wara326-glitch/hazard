# 災害リスクマップ

住所・現在地・地図上の任意地点から、国土地理院の背景地図にハザードマップポータルの公開タイルを重ねて確認するスマートフォン対応Webアプリです。

## 初版の機能
- 住所検索（地理院住所検索）
- 現在地表示
- 地図タップによる地点指定
- 洪水（想定最大規模）
- 土石流・急傾斜地・地すべり
- 津波・高潮・内水
- 公式「重ねるハザードマップ」の同一地点へのリンク
- GitHub Pages自動デプロイ

## 注意
初版は地点ごとのハザードを機械判定せず、検索地点と公的ハザードレイヤーの重なりを目視確認する構成です。データ未整備地域もあるため、実際の避難判断では自治体・気象庁等の最新情報を優先してください。
